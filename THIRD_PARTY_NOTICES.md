# Third-party notices

BoardPrint itself is licensed under the Apache License 2.0 (see `LICENSE` and `NOTICE`). This file lists the third-party components that are **bundled inside the desktop installer**, with the license each one declares and its copyright holder or project URL where its manifest gives one. Development-only tools (devDependencies, Rust build-dependencies and procedural macros, test runners) are not shipped and are not listed.

This file is generated by `scripts/third_party_notices.py` from the manifests and lockfiles (`app/frontend/package-lock.json`, `app/shell/src-tauri/Cargo.lock` via `cargo metadata`, the installed metadata of `app/backend/requirements.txt`) and from the shipped files themselves. Do not edit it by hand: run `.venv/Scripts/python.exe scripts/third_party_notices.py` after changing dependencies (`--check` fails if it is out of date). Licenses are reported as declared by each package; the full license texts are in each package's distribution.

- Web UI (npm, production dependency closure): 240 packages

- Desktop shell (Rust crates linked into the executable): 276 crates in 20 license groups

- Separately shipped binaries and assets: 12 entries
